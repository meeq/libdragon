Detailed Description

MIDI control plane for the SF64 synthesizer.

Author
Giovanni Bajo giova.nosp@m.nnib.nosp@m.ajo@g.nosp@m.mail.nosp@m..com

Implements midi_target_t callbacks, per-channel controllers, Channel Mode Messages (CC120/121/123), RPN pitch-bend sensitivity, bank select, Native/GM1 mode, and GM1 System On. Voice lifecycle stays in sf64_synth.c.

Return the synthesizer as a midi_target_t for MID64 playback.

Preview API:
This API is part of the libdragon preview: it may change without notice. Set LIBDRAGON_PREVIEW=1 (warnings) or 2 (silent) in your Makefile to use it.

Controllers mapped: CC7 volume, CC11 expression, CC10 pan, CC64 sustain, CC0/CC32 bank select, CC6/CC38/CC100/CC101 RPN (pitch bend sensitivity), CC120 All Sound Off, CC121 Reset All Controllers, CC123 All Notes Off. midi_target_ops_t::system_reset handles GM1 System On.
