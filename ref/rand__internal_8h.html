Detailed Description

Internal random number generation functions.

Author
Giovanni Bajo giova.nosp@m.nnib.nosp@m.ajo@g.nosp@m.mail.nosp@m..com

This module provides a simple and fast PRNG, only for internal libdragon use.

Whenever libdragon needs some random number, it should use this module instead of the standard library functions. This is important because C rand() is deterministic and if determinism is needed, users will expect all calls to rand() to happen under their control. If libdragon itself started calling rand() without the user knowing, it would break determinism.
