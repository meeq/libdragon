Detailed Description

MID64 sequence player.

Author
Giovanni Bajo giova.nosp@m.nnib.nosp@m.ajo@g.nosp@m.mail.nosp@m..com

MID64 is the compiled form of a Standard MIDI File produced by audioconv64. The player dispatches MIDI channel events to a midi_target_t (for example an SF64 synthesizer) with sample-accurate timing.

Use mid64player_play / mid64player_stop for mixer-driven playback, or mid64player_decode_next to walk the stream offline (tests and tooling).

Decode the next event and dispatch channel messages to target.

Preview API:
This API is part of the libdragon preview: it may change without notice. Set LIBDRAGON_PREVIEW=1 (warnings) or 2 (silent) in your Makefile to use it.

Tempo meta-events update the player but are not sent to the target. On end of sequence, returns false without calling the target. The now value passed to the target is the absolute MIDI tick of the event.

Returns
true if an event was decoded (including tempo); false on end of sequence
