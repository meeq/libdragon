Detailed Description

Interface for disk operations required to implement a volume.

These interfaces are identical to diskio.h from FatFs. It basically just adds one indirection layer to it, to dispatch the calls to the correct volume.

◆ disk_status

int(* fat_disk_t::disk_status) (void)

Return the current status of the underlying device.

Return the current status of the device. The status can be a combination of:

  • STA_NOINIT: device must be reinitialized
  • STA_NODISK: no medium in the device
  • STA_PROTECT: write protected
