Detailed Description

Bio Sensor accessory interface.

Author
Christopher Bonhage me@ch.nosp@m.rist.nosp@m.opher.nosp@m.bonh.nosp@m.age.c.nosp@m.om

Bio Sensor (NUS-A-BIO-JPN) is an N64 controller accessory to read a player's heartbeat using an infrared sensor. It was only released in Japan, and was only supported by a single retail game, "Tetris 64". The Bio Sensor is a video game accessory. It is NOT a medical device and is for entertainment purposes only.

The Bio Sensor subsystem provides an interface for reading heartbeat data from multiple Bio Sensor accessories connected to different joypad ports. Each port can be independently started and stopped for reading heartbeat data.

Bio Sensor reads are performed at 60Hz (NTSC) or 50Hz (PAL) using the vertical interrupt (VI) handler. The subsystem maintains a rolling window of heartbeat counts to calculate the current heart rate in beats per minute (BPM).

◆ bio_sensor_reader_t

struct bio_sensor_reader_t

Bio Sensor reader context structure.

Maintains state and statistics for heartbeat detection on a single port. Uses a circular buffer to track individual beat timestamps for IBI calculation.

Data Fields
bool read_pending Flag indicating an async read operation is in progress.
bio_sensor_state_t state Current heartbeat detection state.
int64_t beat_timestamps[BIO_SENSOR_BEATS_MAX] Circular buffer storing timestamps of detected heartbeats.
unsigned beat_cursor Current write position in the circular buffer.
unsigned beat_count Total number of heartbeats detected since reading started.

Initialize the Bio Sensor subsystem.

Must be called before starting Bio Sensor reads on any port.

Registers the VI interrupt handler for periodic sensor reads. Uses reference counting to support multiple init/close pairs.

◆ bio_sensor_close()

Close the Bio Sensor subsystem.

Should be called when Bio Sensor functionality is no longer needed.

Decrements the reference count and unregisters the VI interrupt handler when the count reaches zero.

◆ bio_sensor_read_start()

void bio_sensor_read_start ( joypad_port_t  port)

Start reading heartbeat data from a Bio Sensor.

Initializes the reader context for the specified port and begins continuous heartbeat monitoring. The sensor will be read at 60Hz (NTSC) or 50Hz (PAL) via the VI interrupt handler. After starting, it will take 4-5 seconds to accumulate enough data for a heart rate reading.

Parameters
portThe joypad port with the Bio Sensor accessory attached

◆ bio_sensor_get_bpm()

int bio_sensor_get_bpm ( joypad_port_t  port)

Calculate the current heart rate in beats per minute (BPM)

Calculates the average BPM based on heartbeat counts from multiple measurement periods. Requires at least 8 measurement periods (4 seconds) of data before returning a valid BPM. Uses up to 16 periods (8 seconds) for the rolling average calculation.

Parameters
portThe joypad port to read BPM from
Returns
Heart rate in beats per minute, or 0 if insufficient data
