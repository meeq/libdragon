Detailed Description

Video sync helper (frameskipping/seek decisions driven by a master clock)

Author
Giovanni Bajo giova.nosp@m.nnib.nosp@m.ajo@g.nosp@m.mail.nosp@m..com

This module provides a reusable, display-agnostic helper to keep a decoded video in sync with an external master clock (typically audio). It does not perform any rendering or pacing; it only decides what the caller should do (render next, skip next, or seek and render).

◆ video_sync_params_t

struct video_sync_params_t

Parameters controlling sync behavior.

Data Fields
float recovery_time_sec

Desired time to recover from lag (in seconds). Larger => softer recovery.

Default: 1.0

float keyframe_window_sec

If a keyframe exists within this window (in seconds) and budget allows, prefer a seek over present-skip. Use a negative value to disable keyframe-based seeking.

Default: 0.20

float max_lag_sec

If lag exceeds this threshold (in seconds), allow a more aggressive seek towards the current target frame. Use a negative value to disable aggressive seeking.

Default: 0.75
