Detailed Description

Shared state and helpers for the SF64 synthesizer.

Author
Giovanni Bajo giova.nosp@m.nnib.nosp@m.ajo@g.nosp@m.mail.nosp@m..com

Shared by the MIDI control plane (sf64_midi.c) and the voice engine (sf64_synth.c). Not part of the public API.

struct sf64_synth_t

Opaque synthesizer state.

Immutable bank pointer; mutable MIDI channels and mixer voices. Not part of the public API — clients use the typedef in sf64_synth.h.
