◆ KERNEL_TP_INVALID

#define KERNEL_TP_INVALID   ((void *)0x5FFF8001)

Invalid thread pointer value.

This is used to indicate that the current thread pointer is invalid, which happens during exception processing. If the code happens to access TLS, it will dereference this, and the exception code in __get_exception_name will be able to detect this and print an useful error message.
