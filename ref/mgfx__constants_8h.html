◆ MGFX_ATTRIBUTE_POSITION

#define MGFX_ATTRIBUTE_POSITION   0

Input number of the "Position" vertex input.

This attribute expects the object space position as three 16-bit signed integers in s10.5 format. It is equivalent to:

struct position {
int16_t x;
int16_t y;
int16_t z;
}

◆ MGFX_ATTRIBUTE_NORMAL

#define MGFX_ATTRIBUTE_NORMAL   1

Input number of the "Normal" vertex input.

This attribute expects the object space normal as three normalized signed integers (in the range -1 to 1) packed into 16 bits. The x, y and z components are encoded as 5, 6 and 5 bits each, like so: |16-------------------------—0| |x x x x x y y y y y y z z z z z|

◆ MGFX_ATTRIBUTE_COLOR

#define MGFX_ATTRIBUTE_COLOR   2

Input number of the "Color" vertex input.

This attribute expects the RGBA color as four normalized 8-bit unsigned integers (in the range 0 to 1). It is equivalent to:

struct color {
uint8_t r;
uint8_t g;
uint8_t b;
uint8_t a;
}

◆ MGFX_ATTRIBUTE_TEXCOORD

#define MGFX_ATTRIBUTE_TEXCOORD   3

Input number of the "Texture coordinate" vertex input.

This attribute expects the texture coordinates as two 16-bit signed integers. The scale and offset of the texture coordinates can be adjusted in mgfx_texturing_parms_t. The format is equivalent to:

struct texcoord {
int16_t s;
int16_t t;
}
