bool __cpakfs_n64_string_valid ( uint8_t  ch)

Check whether a character is valid in the N64 codepage.

The N64 codepage is a 8-bit codepage where not all characters are valid. This function checks whether the provided character is valid or not. Invalid characters cannot be converted to UTF-8.
