Detailed Description

Internal API for accessing the SYMT symbol table.

Author
Giovanni Bajo giova.nosp@m.nnib.nosp@m.ajo@g.nosp@m.mail.nosp@m..com

The SYMT file, normally embedded in the rompak, allows to symbolize addresses for debugging purposes. It is mostly used by backtrace.c to create symbolized backtraces. The SYMT file is generated by the n64sym tool.

Since it is shipped by default, the format is quite complex as it is designed in a way to be directly queried from ROM, while still being as compact as possible ot reduce ROM size, and use as little as 512 bytes of RAM at runtime. The format is described in symtable.c
