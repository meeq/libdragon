◆ wav64_state_vadpcm_t

struct wav64_state_vadpcm_t

WAV64 VADPCM decoding state (for a single mixer channel)

Notice that the state is accessed in part by RSP (state[2]) and in part by the CPU (bitpos) so we need to avoid false-sharing of cachelines. This is why we force a 16-byte alignment, so that it spans exactly 2 cachelines.

Data Fields
wav64_vadpcm_vector_t state[2] Current decompression state.
int bitpos Current bit position in the input buffer.

◆ wav64_vadpcm_skippoint_t

struct wav64_vadpcm_skippoint_t

Skip point in the waveform.

This structure encodes the state of the VADPCM decoder at a skip point in the waveform. It is used to restore the state of the decoder when skiping to a different point in the waveform.

Data Fields
int offset Samples offset of the skip point in the waveform.
int bitpos Bit position in the input buffer.
