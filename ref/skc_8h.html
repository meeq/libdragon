Detailed Description

SKC - Secure Kernel Calls.

Author
Giovanni Bajo giova.nosp@m.nnib.nosp@m.ajo@g.nosp@m.mail.nosp@m..com

This module defines the interfaces to do the secure kernel calls (SKC) on the iQue Player. These are basically syscalls into the kernel to perform security-sensitive operations like cryptography, launching an application or so on.

Reset the watchdog timer to keep the application alive.

On iQue, applications running as trials are expected to call this function to keep themselves alive. Otherwise, the secure kernel (via the kernel timer) might reset them.
